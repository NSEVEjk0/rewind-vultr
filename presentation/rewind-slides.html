Executed investigation, precise approval, independent verification

The agent investigates. You approve the cells.

1. Inspect versionsGood copy, incident checkpoint and today’s file are read by trusted gVisor workers on Vultr.
2. InvestigateVultr Inference writes diagnostic code. It runs in its own sandbox and compares the actual files.
3. Review the scopeThe controller validates the proposed cells and protects observed later edits. The operator approves the exact plan.
4. Generate the repairA second Vultr call writes the approved recovery. Each key-and-field pair is explicit.
5. Execute on copiesThe repair runs in another gVisor container. Originals stay read-only and unchanged.
6. Verify and exportA fresh trusted worker inspects the result. Every cell and all teardown checks must pass before download.

The model receives the incident description, structure and aggregate findings. Snapshot contents and extracted record values stay outside inference requests. Generated code never receives the acceptance answers.
