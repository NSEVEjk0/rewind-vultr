Rewind helps you restore damaged prices or other database fields from a good backup, while keeping newer invoices and updates. Choose what to fix, check the result, and download the recovered copy.

Choose a good backup and a current export. This first version supports one table, one stable primary key, and files up to 256 KB each.

Export consistent copies with SQLite’s Online Backup API. A live database file without its WAL or journal is not a complete snapshot.

Restore only what went wrong.

Give Rewind a good backup and a consistent current snapshot. Choose the damaged fields and records.

Vultr AI writes a recovery program for that selection. A disposable gVisor environment runs it on copies. A fresh, separate checker compares the resulting database with both inputs.

You can download the result only when the selected cells match the backup, every other cell matches today’s snapshot, and all temporary environments have been removed.

This first version supports small SQLite files with matching schemas and one stable primary key. It cannot tell whether a later edit to the same selected cell was legitimate; you decide which cells to restore.
